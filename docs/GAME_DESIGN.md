# Game design

## Premise

A child begins on a tiny floating island with a backpack and magical compass. There is no final boss, final level or fixed map. Each adventure changes the conditions used to select future adventures. Originality against all existing games has not been established.

## Core loop

Explore an island → discover a creature, puzzle or mystery → choose an action → observe a persistent consequence → follow a new opportunity.

## Core systems

- **Wonder Compass:** points toward reachable, undiscovered creatures, locations and mysteries. Provide a fallback discovery when no eligible event exists.
- **Living World Memory:** creatures remember help; settlements remember discoveries; environments preserve changes.
- **World Mutation:** seeds can grow bridges, awaken creatures or transform islands through authored rules.
- **Evolving Companions:** shared experiences unlock abilities, rather than conventional levels. River exploration might unlock a water ability. Defer a broad ability system until the core loop is fun.

## The Lost Cloud

A cloud creature is trapped in a crystal. Freeing it creates a friendship; its rain later restores a forest; the forest yields seeds that open new islands. Studying the crystal can reveal its history and another route to freeing the cloud. Avoid permanently punishing curiosity or locking a child out of progression.

Make each consequence visible and explain why it happened. A journal can record “You helped the cloud, so its rain grew this forest.”

## Endless exploration

Generate finite islands on demand with seeded rules. Retain player changes and revisit history. Endless map generation does not guarantee endless interesting content: author event variations, meaningful prerequisites and repetition limits.

## Experience principles

Readable controls, short dialogue, clear feedback and recoverable mistakes. Support stopping at any time with reliable saves. Target age range and reading level remain to be decided through playtesting.
