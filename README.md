# WONDERTAIL

An endless adventure where the world remembers everything you do.

**Design principle: Every kindness creates a new adventure.**

An offline-first, 2D top-down children's adventure planned for Flutter and Flame. Start on a floating island with a backpack and magical compass. Help creatures, transform environments, and discover islands shaped by your earlier choices.

## Project status

Planning repository. No runnable Flutter application exists yet. The first target is a fun, replayable 15-minute prototype, not an unlimited content catalogue.

## First implementation task

Initialize the Flutter application in this repository, preserving these documents. Select compatible Flutter, Flame, persistence and audio package versions at implementation time. Build one hand-designed island with movement, camera tracking and collisions before procedural generation.

## Content policy

Offline play; no generative AI, unrestricted chat, interruptive ads or manipulative daily streaks in the MVP. Third-party reference images are not bundled or licensed game assets. Distribution licensing is undecided; no open-source license is granted by this repository.
